# Data and metric definitions
The four primary splits have 4, 3, 12 and 12 disjoint seeds with 32 jobs each. All identifiers and seed namespaces are unique. These are synthetic draws from small discrete state spaces: substantively equivalent cases can recur. The museum manifest is balanced by seed and authored in a separate generator. It has a different booking and substitution mechanism but shares the enforcement vocabulary and assessor. The transfer test is a specified reversal stress, not a representative sample of museums. Neither the team nor the paper claims independent external authorship. No real records. The adaptive follow-up uses ten new blocks of 96 chronological jobs, in three 32-job periods.

The target is client or archive; the other endpoint has independent previous knowledge. Prior A/B represents one legitimate historical receipt. A preliminary A expires at tick 3; another public observer receives a separate offer at tick 4. Staff receives a document at tick 6, a copy is proposed for the other public observer at tick 7, and a requested B arrives at tick 7 or later. Ties process the document copy first. The courier route carries opaque messages through zero, one or two intermediate nodes, never granting payload access to a router. Jobs are independent across the primary study; observers accumulate history only inside their job. Only the supplementary estimator carries cue/outcome counts between closed jobs. Latency is a logical schedule, not distributed wall-clock measurement. A prior and required receipt may match, so exact utility can be achieved through earlier deliveries.

A secure result requires the exact set of demanded receipts at the target, a staff document when commissioned, and zero forbidden deliveries. Additional authorized items do not invalidate completion. Exposure means any boundary delivery violating true scope, expiry or complementary-share rules. Post measures workflows containing a restricted delivery after authoritative withdrawal. Divide by withdrawn workflows for conditional rates. Reconstructed counts distinct public observer-workflows holding both shares; denominator two observers per job. Correct is recovered XOR matching the planted bit. No semantic language judge. Exact completion alone ignores exposure. Allowed blocks counts refused proposals that were admissible at that instant under true state. Single-block recoverability counts safe incomplete runs made safely complete by flipping one denial, later deliveries frozen. This is a diagnostic, not a realizable counterfactual replan. Scores use the assessor's actual roots, not the broker's observed labels.

For a degraded job, nonverified methods see a grant change after its configured lag. The field may be correct, inverted or absent. Original full's boolean ancestry interface maps missing to unmarked; this modeling choice is a stress test, not an inherent property of information-flow control. Checked methods receive correct evidence about both current authority and provenance only when a lookup is available. They deny unverifiable documents even when a true release would be permissible. The base issuer, trusted verification service, recipient identity and history are reliable by construction. Changes during a gateway decision, colluding recipients, secret-dependent timing, real transport loss, queue races and unmodeled routes are outside this study.
